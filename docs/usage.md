# 使用流程与当前可用内容

## 当前可用内容

0.1.0 是可启动的本地桌面基础版，支持项目创建/编辑/删除、多项目窗口、环境管理、服务器连接信息、手动服务/容器映射、本地持久化及命令预览/复制。

## 启动

开发环境执行 `pnpm dev`，或先 `pnpm build` 再 `pnpm start`。Mac 本机测试 APP 可用 `pnpm package:mac` 生成；尚未签名公证或正式发布。

## 操作流程

1. 新建项目及初始环境，在项目卡片点击“打开工作区”。
2. 在“服务器配置”添加服务器，选择 SSH 或 JumpServer 并填写地址、端口、用户及必要的目标资产名称。
3. 在“服务日志”添加服务，为每个实例选择服务器和容器名称。
4. 选择只看新日志、最近 N 行或指定时间，复制相应 Docker 日志命令。
5. 在“方法诊断”填写完整类名及具体方法名，选择模板并复制 Arthas 命令。
6. 点击“项目管理”打开其他项目，各窗口独立工作。

配置会保存到本机，重启后可重新打开项目。当前不会自动连接服务器、读取真实日志或执行诊断，也不要求录入密码或私钥。后续接入会在这些现有工作区中增加真实连接能力。

## 当前配置删除行为

删除项目有原生确认，会关闭其工作区，只删除本地项目配置。服务器被实例引用时须先调整服务配置；环境仅能在没有服务和服务器时删除，项目至少保留一个环境。

## 日志与诊断的区别

日志查看复用 Docker 现有输出及其保留范围；Arthas 观察启动监控之后发生的方法调用。历史日志不能自动还原当时未采集的方法参数或耗时树。

## 后续远程功能的预期状态

| 情况         | 预期表现                             |
| ------------ | ------------------------------------ |
| 某实例无流量 | 增强完成后显示等待调用               |
| 其他节点命中 | 标记具体实例和服务器                 |
| 容器已重建   | 核对新身份，不继续使用旧诊断会话     |
| 部分节点失败 | 分别展示失败原因和其他节点结果       |
| SSH 断线     | 显示连接及远端任务状态未知，重连核对 |
| 用户停止     | 仅中断本任务，确认后显示已停止       |
| 关闭项目窗口 | 清理所属订阅与任务，保留其他窗口连接 |

## 所需条件

参见[连接说明](connections.md)与[Arthas 接入](arthas.md)。APP 不应自动扩大服务器权限，也不能假定日志权限等于诊断权限。
