# TraceLogDock v0.3.20 · 预览版

无需下载源码或安装Node.js，直接下载下方对应系统的安装包。

- **Mac Apple Silicon（M系列）**：`TraceLogDock-0.3.20-mac-arm64.dmg`，打开DMG后将APP拖到“应用程序”。不适用于Intel Mac。
- **Windows x64**：`TraceLogDock-Setup-0.3.20-x64.exe`，双击并按安装向导选择目录。
- `SHA256SUMS.txt`提供两个安装包的SHA-256校验值。

当前仓库为私有，下载时需要登录有该仓库访问权限的GitHub账号。

## 本次迭代

- 服务器配置位于菜单第一项，打开项目先配置和连接服务器。
- 服务日志独立显示，日志框随窗口高度扩展；支持时间范围、单选或合并多个日志源。
- SERVICES列表支持编辑和删除，容器发现列表可关闭与重新展开。
- SSH/JumpServer密码可记住，同一堡垒机登录可复用到独立目标终端。
- 默认通过同步入口进行单次请求深入诊断，结果优先展示慢点、代码位置与本地优化方向。
- 支持Arthas运行反编译源码查看与独立AI配置；未接AI仍有本地建议。

## 构建与验证范围

发布流程在GitHub原生Mac arm64与Windows x64环境分别构建，完成对应平台行为检查、安装包校验和安装后APP的项目/日志/诊断隔离回归后才提供下载。Windows流程同时检查NSIS安装与卸载；测试SSH和模型服务均为本机虚构fixture，不连接生产。

Mac为ad-hoc签名，尚未Apple公证；Windows尚未配置发布者代码签名。系统来源确认应核对下载来源后由用户处理。自动化验证不代替所有Windows 10/11系统版本、真实JumpServer策略和Docker镜像的兼容性验收。

升级前完全退出旧版，再运行安装或替换APP。项目与加密凭据保存在系统用户目录，不随APP安装目录替换；日志显示缓存不会作为持久日志保存。
