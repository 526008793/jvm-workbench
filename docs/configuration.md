# 配置与示例

## 当前状态

[示例 JSON](../examples/workspace.example.json)用于讨论配置模型，当前没有配置导入或应用运行时校验器。不能把它当作已经稳定的公共 API。

## 配置组织

项目拥有环境、服务器和服务映射。每台服务器引用直连 SSH 或 JumpServer 连接配置；连接方式不由项目固定。

| 字段          | 意义                                     |
| ------------- | ---------------------------------------- |
| schemaVersion | 本地配置格式版本，变更时明确迁移语义     |
| project.id    | 项目标识，与显示名称分离                 |
| environments  | 环境及服务器/服务归属                    |
| connections   | 两种连接配置与秘密引用                   |
| credentialRef | 指向单独存储的凭据，不是密码             |
| servers       | 服务器身份、连接配置和必要的资产选择信息 |
| services      | 容器匹配规则及服务名称                   |

示例展示同一项目混合两种连接方式。地址使用保留示例域名，凭据引用无效；实际创建时由 UI 生成标识并保存真实凭据引用。

## 秘密管理

未来秘密单独通过 Electron safeStorage 加密，项目 JSON 仅保留引用。私钥路径和私钥口令分别处理，不默认将私钥复制入项目目录。OTP 不落盘。

safeStorage 可用性、macOS 和 Windows 迁移行为要发布前验证，不可用时不能静默保存明文。当前仓库不含凭据存储实现。

## 配置导入导出

首期先实现本机项目管理。未来若提供导入导出，默认仅导出不含秘密的项目结构，并明确无效凭据引用需要重新绑定。配置迁移和跨设备导出不能未经设计混为一谈。
