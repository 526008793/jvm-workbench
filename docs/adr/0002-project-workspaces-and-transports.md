# ADR 0002：项目工作区与连接适配

## 状态

已采纳。

## 背景

需要同时查看不同项目，一个项目可能有多台服务器、多实例，也可能混用直连 SSH 与 JumpServer。

## 决定

按项目打开工作区窗口，窗口内按环境、服务、实例导航。连接方式归服务器配置，SSH 与 JumpServer 适配共享执行/流/中断能力，Docker 与 Arthas 逻辑位于上层。

任务、认证提示和结果绑定明确项目上下文，不使用全局“当前项目”决定所有窗口的远程目标。关闭窗口只清理其使用的资源。

## 代价与验证

需要明确连接共享条件、引用生命周期和任务归属。并发会话受 JumpServer 部署约束，不能承诺一次 MFA 复用全部资产。多窗口隔离必须有行为验证。
