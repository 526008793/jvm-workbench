# ADR 0003：首期 Docker 与按需 Arthas

## 状态

已采纳为首期范围，权限、版本和目标镜像待验证。

## 背景

已确定的使用场景通过 Docker logs 查看 Java 微服务日志，并希望省去手动进入容器下载和启动诊断包。

## 决定

首期通过目标服务器 Docker CLI 发现容器和读取日志。Arthas 使用固定版本工具包预置或获准分发，通过容器内真实 Java 进程按需加载。优先交付可用文本结果，有实际可达 HTTP API 时再使用结构化结果。

## 代价与验证

Docker logs 权限不代表 exec/attach 权限。需验证镜像、Java、目标用户及传输渠道。容器 loopback 与宿主机 loopback 不同，不能凭端口转发就假定 HTTP API 可达。退出客户端、-n 和本地计时器都不能未经验证当作远端任务停止保证。
