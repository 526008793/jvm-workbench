# 路线图

所有应用里程碑当前均未完成；这里记录范围和完成条件，不提供未经验证的交付日期。

| 阶段          | 交付内容                                     | 完成条件                                     | 状态     |
| ------------- | -------------------------------------------- | -------------------------------------------- | -------- |
| M0 仓库基础   | README、架构、社区规范、示例、文档 CI        | 本地检查通过，仓库内容可评审                 | 本轮范围 |
| M1 接入验证   | SSH/JumpServer 最小连接及 Docker/Arthas 试验 | 记录认证、并发、exec、attach、停止的实际能力 | 待开始   |
| M2 Mac 日志版 | 应用骨架、项目窗口、配置、连接、容器与日志   | 两项目、双连接方式、多节点日志闭环           | 待开始   |
| M3 方法诊断版 | 搜索候选、模板、原始结果、多实例任务和停止   | 按实例状态可核对，停止不影响其他任务         | 待开始   |
| M4 增强       | SLS 历史、结构化结果展示、更多发现能力       | 各项另有明确需求与兼容验证                   | 后续     |
| M5 Windows    | 系统差异适配和安装包                         | 认证、凭据、日志及诊断完整验收               | 后续     |

## M1 的决策输出

确定 SSH 库与 PTY 行为、JumpServer 实际接入方式、工具包分发路径以及 Arthas 文本/HTTP 数据通道。记录已验证版本和限制，失败时针对实际条件调整实现，不先承诺所有部署兼容。

## 首期发布边界

首期应用应覆盖 Mac、多项目工作区、SSH/JumpServer 双接入、Docker 日志及 Arthas 快捷诊断。M2 可先作为明确标示能力范围的预览版；发布流程与版本号见[发布指南](releasing.md)。
